Cookit Android A14.5 / C3

Base required: installed/source A14.4.5 (versionCode 16).

Apply ZIP at Android repo root, then:
  git diff --check
  grep -nE 'versionCode|versionName' app/build.gradle.kts
  git switch -c update/cookit-0.14.5-c3-fiscal-agent-loop
  git add -A
  git diff --cached --check
  git commit -m "Cookit Android 0.14.5: C3 cloud fiscal agent mock loop"
  git push -u origin update/cookit-0.14.5-c3-fiscal-agent-loop

GitHub Actions must build the persistently signed debug APK with the existing Cookit signing certificate.
