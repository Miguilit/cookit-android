# Cookit Android — iOS-inspired UI final pass

Date: 2026-09-29
Target: 0.15.0.48 / versionCode 83
Base: iOS-inspired UI P1 on top of the functional Android 0.15.0.47 baseline.

## Goal

Finish the visual convergence with CookitPad without turning Android into an iOS clone.
Android navigation, information architecture and POS workflows stay unchanged.

## Final visual refinements

- thinner tablet side rail and top chrome;
- denser POS spacing, closer to CookitPad;
- cyan as the active/action accent; orange remains brand/attention;
- green reserved for success/state semantics rather than prices;
- smaller category pills with a subtle cyan selected state;
- denser product grid and product cards;
- slimmer cart, compact quantity controls and action buttons;
- reduced excessive corner radii;
- dashboard metric accent aligned to cyan.

## Functional guard

No POS, order, cash-register, API, printer, offline, database, fiscal, FDM or Module2 workflow is changed by this pass.
